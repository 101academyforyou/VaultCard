## App 審查資訊（Review Notes）

審查人員多半讀英文，建議用英文填寫。

- **登入資訊**：取消勾選「需要登入」
- **備註**：

```
VaultCard is a digital business card and personal contact-notes app. No account or sign-in is required, and there is no backend server: card data is encoded directly in the share link (after the "#", which browsers never send to a server), and saved contacts are stored only on the device. The app collects no data and contains no ads.

VaultCard is an independent app and is not affiliated with Obsidian (Dynalist Inc.); this is stated in the description and in the app's settings page.

Native, interactive features:
- Create your own card with a live preview; the app generates a QR code and a share link (system share sheet)
- Save received cards as Markdown contact notes with properties (where/when you met), tags, [[links]] between people, backlinks and "met at the same event"
- An interactive, draggable/zoomable network graph of your contacts (with haptic feedback)
- Export all contacts as a .zip of Markdown notes, single cards as vCard, and JSON backup/restore

How to review:
1. Open the "名片" (Card) tab, type a name to see the card preview and QR code.
2. Open the "人脈" (People) tab and tap "看範例名片" (View sample card), then tap "存進我的人脈" (Save) to add a sample contact.
3. Open the contact, write a note such as [[Alex]] to create a link, then open the "圖譜" (Graph) tab.
```
